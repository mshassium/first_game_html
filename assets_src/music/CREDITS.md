# Происхождение звука

Требование [07-audio-spec.md](../../docs/gdx/07-audio-spec.md) §1: у каждого звукового файла
должно быть записано, откуда он взялся. Для сгенерированного это важнее, чем для CC0:
условия использования зависят от тарифа и редакции пользовательского соглашения.

## Открытый вопрос по лицензии

**Право на коммерческое использование сгенерированного в Suno не проверено.**

Оно зависит от тарифа (на бесплатном его нет) и от текущей редакции Terms of Service.
До публикации в сторах нужно открыть актуальные Terms, убедиться, что тариф разрешает
коммерческое использование в игре, и записать сюда дату проверки и цитату.

Пока это не сделано, музыка считается пригодной только для разработки.

## M-01 — `music_menu.mp3`

| Поле | Значение |
|---|---|
| Источник | Suno, генерация по промпту [10-audio-prompt-book.md](../../docs/gdx/10-audio-prompt-book.md) §2, M-01 |
| Дата | 26 июля 2026 |
| Тариф | не зафиксирован |
| Лицензия | не проверена, см. выше |
| Исходник | `music_menu.mp3`, 4:20, 48 кГц, стерео, 184 кбит/с, −13.9 LUFS |
| В игре | `gdx/assets/audio/music_menu.mp3`, 80 с, 44.1 кГц, стерео, 128 кбит/с, −20.2 LUFS |

### Как из исходника получена петля

Трек генерируется с началом и концом, зацикливать его как есть нельзя. Петля собрана
по [10-audio-prompt-book.md](../../docs/gdx/10-audio-prompt-book.md) §4.2.

Участок выбран по профилю громкости: с 90-й по 170-ю секунду фактура полная и ровная,
уровни на границах совпадают (−11.1 и −12.3 LUFS momentary), поэтому стык не выдаёт
себя скачком громкости.

```bash
# A — тело петли: 80 с с 90-й секунды
ffmpeg -i music_menu.mp3 -vn -ss 90 -t 80 -ar 44100 -ac 2 A.wav

# B — ровно те 2 с, что идут сразу после A
ffmpeg -i music_menu.mp3 -vn -ss 170 -t 2 -ar 44100 -ac 2 B.wav

# B кроссфейдом ложится на начало A → петля ровно 80 с
ffmpeg -i B.wav -i A.wav -filter_complex "[0][1]acrossfade=d=2:c1=tri:c2=tri" loop.wav

# Финал: -20 LUFS, стерео MP3 128 кбит/с
ffmpeg -i loop.wav -af "loudnorm=I=-20:TP=-1:LRA=11" \
  -ar 44100 -ac 2 -b:a 128k gdx/assets/audio/music_menu.mp3
```

Ключ `-vn` обязателен: в исходнике лежит обложка отдельным видеопотоком, без него
она утаскивается в результат и раздувает файл.

### Что осталось проверить на слух

Стык петли сведён по уровню, но музыкальную непрерывность машина не оценит.
Послушайте три круга подряд: не должно быть ни щелчка, ни ощущения «музыка началась
заново». Если слышно — сдвиньте точку выреза на такт и пересоберите.

# 05 — Промпт-бук v3: «Стол гика» (принят 19.08.2026)

Заменяет v1/v2 (медальоны, фэнтези-UI). Промпты не дублируются: **источник истины — `PROMPTS*.md` в папках арт-лаборатории** (`docs/gdx/12-art-direction-lab/e*/`), там же референсы и история правок. Здесь — метод и карта «какой ассет — откуда».

## Метод генерации предметов стола

1. **Эталон стиля — жетон-капкан** `e4-effects/out/TRAP_gpt-5.4-image-2_1.png`: всегда приложить референсом к любому предмету (жетон, фигурка, кубик, UI-предмет) с фразой *«match the attached token exactly in style, material, size and camera»*.
2. **Камера строго сверху (~70–75°)** для всего, что лежит на столе; для фигурок и свечи — референс камеры `e3-living-table/refs/judge_minis_topdown.png`.
3. **Свет запекается**: *«dim warm room light, warm from the top-right, cool soft shadow on the lower-left, muted matte painted finish»* + референс фона `e3-living-table/out/BG_*.png`. Поверх в игре ничего не тонируется.
4. **Фон для вырезки**: чистый зелёный `#00FF00`; для зелёных предметов — пурпурный `#FF00FF`. Вырезка `tools/artlab/keyout.py <папка> [magenta]`.
5. **Без текста** (кроме букв карт), без логотипов и копий чужих персонажей/механик; «in the spirit of», архетипы.
6. **Листы** (пять карт / шесть граней в ряд) режутся `tools/artlab/cardtest.py` (по яркости на чёрном) или по альфе после хромакея.
7. Модель — `openai/gpt-5.4-image-2` через OpenRouter (см. `tools/artgen`); 2K; цена ~$0.015–0.035 за картинку.

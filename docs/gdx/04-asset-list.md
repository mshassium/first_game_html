# 04 — Полный список ассетов

Все размеры даны для **исходника** (`assets_src/`) и для **игрового** варианта (`gdx/assets/`). Исходник всегда крупнее — это запас на будущие экраны высокой плотности и на перекадрирование.

Условные обозначения: **A** — требуется прозрачность (альфа-канал по контуру), **9P** — файл размечается как 9-patch (`.9.png`), **L** — лист: генерируется одним изображением и режется.

## 4. Шрифты — `assets/fonts/`

**Сделано.** Шрифты не генерируются нейросетью: `./gradlew tools:bakeFonts` печёт
`.fnt` + PNG-страницы из OFL-шрифтов в `assets_src/fonts/`. Freetype в проект не тащим —
он не работает в TeaVM, а два разных пути загрузки шрифтов на разные платформы дороже,
чем один раз испечь растр.

| Роль | Шрифт | Лицензия | Кегль | Эффекты |
|---|---|---|---|---|
| Буквы карт (F/I/R/S/T) | **Cinzel Decorative Bold** | OFL | 128 | Золотой градиент + обводка + тень |
| Крупные заголовки | **Forum** | OFL | 56 | Тёплый градиент + обводка + тень |
| Заголовки UI, кнопки | **Forum** | OFL | 36 | То же |
| Основной текст, лог, правила | **PT Sans** Regular/Bold | OFL | 28 | Обводка + мягкая тень |

**Кириллица обязательна** для Forum и PT Sans — обе поддерживают. Cinzel Decorative
только латинский, и этого достаточно: он используется исключительно для букв F, I, R, S, T,
а цвет школы накладывается тинтом в движке.

Набор символов: латиница + кириллица + цифры + пунктуация + `«»—–…×✦№°•→←`.

## 6. Бюджет и упаковка

| Атлас | Размер | Содержимое |
|---|---|---|
| `cards.atlas` | 2048×2048, 1 страница | C-01…C-07 |
| `ui.atlas` | 2048×2048, ≤2 страницы | U-01…U-51 |
| `vfx.atlas` | 1024×1024, 1 страница | V-01…V-15 |
| фоны | отдельные JPEG | B-01…B-04 |

**Целевой вес `gdx/assets/` ≤ 25 МБ**, из них графика ≤ 15 МБ, звук ≤ 8 МБ, шрифты ≤ 2 МБ. Это верхняя граница комфортной загрузки веб-версии.

Сжатие: PNG прогоняем через `pngquant --quality=80-95` (даёт 50–70 % экономии без заметной потери), JPEG — качество 85, прогрессивный.

TexturePacker: `filterMin: MipMapLinearLinear`, `filterMag: Linear`, `paddingX/Y: 4`, `duplicatePadding: true`, `maxWidth/maxHeight: 2048`, `bleed: true`.

## 7. Постобработка каждого ассета

1. Скачать сырую выдачу в `assets_src/raw/` (в `.gitignore`).
2. Удалить фон (для элементов с **A**) — предпочтительно генерировать сразу на прозрачном/однотонном фоне; при необходимости — `rembg` или ручное выделение.
3. Обрезать до контента, выровнять по сетке, привести к целевому размеру исходника.
4. Проверить края: полупрозрачная кайма не должна содержать цветной ореол от удалённого фона.
5. Сохранить в `assets_src/<категория>/` под именем из этого документа.
6. Ресайз в игровой размер (Lanczos), `pngquant`, положить в `gdx/assets/raw_packed/`.
7. Для 9P — разметить растяжимые области и safe-зону, сохранить как `.9.png`.
8. Перепаковать атласы, запустить игру, посмотреть вживую.

## 8. Чек-лист приёмки ассета

- [ ] Соответствует style-блоку из [03-art-style-bible.md](03-art-style-bible.md) §10
- [ ] **Нет ни одного текстового символа** (кроме абстрактных глифов на рунных кольцах)
- [ ] Освещение: ключ сверху-слева, rim-light сверху — совпадает с остальными ассетами
- [ ] Палитра: не более двух акцентных цветов, база доминирует
- [ ] Чистая альфа, нет ореола от удалённого фона, нет обрезанных краёв
- [ ] Читается при уменьшении до 120 px (для карт) / 32 px (для иконок)
- [ ] Ч/б-тест: композиция держится без цвета
- [ ] Точный целевой размер и центрирование
- [ ] Рядом с уже принятыми ассетами не выбивается — проверка «положить в ряд и посмотреть»

# 01 — Формальная спецификация правил F!RST

Источник истины — поведение `index.html` (v18) на момент создания ветки. Всё ниже выверено по коду, а не по тексту правил в игре. Расхождения между кодом и внутриигровым текстом вынесены в §8.

## 1. Сущности

```
Letter        = F | I | R | S | T
Side          = YOU | AI
SideState     = deck: List<Letter>       // 50 карт: по 10 каждой буквы, перемешаны
                hand: List<Letter>       // максимум 7
                space: List<Letter>      // выложенные карты, порядок сохраняется
                discard: List<Letter>
Traps         = forbidYou: Letter?       // буква, запрещённая ИГРОКУ
                forbidAI:  Letter?       // буква, запрещённая ИИ
                trapYou:   Int           // счётчик ловушек, висящих на игроке
                trapAI:    Int
GameState     = you, ai, turn: Side, firstPlayer: Side, firstTurnDone: Bool,
                over: Bool, elapsedSec: Int
```

**Важно:** у каждой стороны **своя отдельная колода** из 50 карт. Общей колоды нет.

## 2. Начало партии

1. Обе колоды строятся как 10×F + 10×I + 10×R + 10×S + 10×T = 50 карт и перемешиваются (Fisher–Yates).
2. Каждая сторона берёт **5 карт** в руку. В колодах остаётся по 45.
3. Бросок двух кубиков d6. При равенстве — **перебросить оба**, пока значения не разойдутся. Большее значение ходит первым.
4. Запускается таймер партии (счёт вверх, формат `MM:SS`).
5. Первый игрок **не берёт карту** в свой первый ход (см. §3.1).

## 3. Структура хода

### 3.1 Фаза добора
Если это не первый ход первого игрока — активная сторона берёт 1 карту из своей колоды.
- Если колода пуста в момент обязательного добора → **активная сторона немедленно проигрывает** (причина `DECK_OUT`).
- После добора применяется лимит руки (§4).

Флаг `firstTurnDone` выставляется в `true` при первом же входе в фазу добора и больше не сбрасывается.

### 3.2 Фаза ловушки
Если на активной стороне висит ловушка (`trap* > 0`):
- при непустой руке — сбрасывается **ровно 1 карта** из руки, счётчик обнуляется (`= 0`, не декремент);
  - игрок выбирает карту сам через модалку;
  - ИИ сбрасывает **случайную** карту;
- при пустой руке — счётчик просто обнуляется, ничего не сбрасывается.

После срабатывания ловушки ход **продолжается**: активная сторона всё равно разыгрывает карту.

### 3.3 Фаза розыгрыша
Активная сторона выкладывает **ровно 1 карту** из руки.

Проверка запрета: если буква разыгрываемой карты совпадает с запретом, наложенным на эту сторону:
- карта уходит в **DISCARD** активной стороны, а не в SPACE;
- **эффект карты не срабатывает**;
- запрет снимается (`forbid* = null`);
- ход завершается.

Иначе: карта кладётся в конец `space`, срабатывает эффект (§5).

### 3.4 Проверка победы и передача хода
После розыгрыша и полного разрешения эффекта проверяются условия победы (§6). Если игра не закончена — ход переходит к оппоненту.

## 4. Лимит руки

Максимум **7 карт**. При превышении лишние карты уходят в сброс **с конца руки** (то есть выбрасывается самая свежедобранная карта), без выбора игрока. Проверка выполняется после каждого добора и после возврата карты эффектом R.

Практическое следствие: добор при полной руке сжигает карту колоды впустую.

## 5. Эффекты карт

| Буква | Название | Эффект |
|---|---|---|
| **F** | FORBID | Активная сторона выбирает букву. Пока запрет висит, первая же попытка оппонента разыграть эту букву отправляет карту в его сброс без эффекта, после чего запрет снимается |
| **I** | INCREASE | Активная сторона берёт +1 карту из своей колоды (пустая колода → поражение) |
| **R** | RECOVER | Активная сторона возвращает 1 карту из своего сброса в руку. Если сброс пуст — эффект не срабатывает |
| **S** | STEAL | Активная сторона выбирает карту в SPACE оппонента и отправляет её в сброс оппонента. Если SPACE оппонента пуст — эффект не срабатывает |
| **T** | TRAP | Счётчик ловушек оппонента +1. Сработает в фазе ловушки его следующего хода |

### 5.1 Детали запрета (F)
- Слот запрета **один на сторону**. Повторное разыгрывание F перезаписывает предыдущий запрет.
- Запрет не имеет срока годности: висит, пока не сработает или не будет перезаписан.
- Запрет можно наложить на **любую** из 5 букв, включая ту, которой у оппонента нет.
- **Информационная асимметрия:** игрок видит, какую букву он запретил ИИ (бейдж с буквой на карте F в своём SPACE), но не видит, какая буква запрещена ему самому — подсвечивается только факт наличия запрета (свечение карты F в SPACE ИИ). Это осознанная механика скрытой информации, переносим как есть.

### 5.2 Детали возврата (R)
- Игрок выбирает **букву** (уникальные буквы из сброса), из сброса удаляется последнее вхождение этой буквы.
- ИИ выбирает без стратегии — берёт последнюю карту сброса.

### 5.3 Детали кражи (S)
- «Кража» — название историческое: карта не переходит к вору, а идёт в сброс **владельца**.
- Игрок выбирает конкретную карту из SPACE оппонента (в текущем UI выбор по индексу списка).
- ИИ всегда берёт **последнюю** карту в SPACE игрока.

## 6. Условия завершения

Победа стороны, если в её **SPACE**:
1. `FIRST` — присутствуют все пять разных букв (по одной и более каждой), **порядок не важен**; или
2. `FIVE_OF_A_KIND` — 5 и более карт одной буквы.

Поражение стороны:
3. `DECK_OUT` — колода пуста в момент обязательного добора (фаза добора или эффект I).

Проверка выполняется после разрешения эффекта разыгранной карты. Одновременная победа невозможна: ход всегда за одной стороной, а эффект S не может создать победу.

## 7. Логика ИИ (текущая)

Приоритет выбора карты из руки, сверху вниз:
1. `S`, если SPACE игрока не пуст;
2. `R`, если свой сброс не пуст;
3. `F`;
4. `T`;
5. `I`;
6. первая карта в руке.

Выбор буквы для запрета: самая частая буква в SPACE игрока; если SPACE пуст — случайная.

**Слабости, которые стоит починить** (не меняют правила, только силу ИИ):
- ИИ никогда не думает о собственной победе — не достраивает `FIRST` и не собирает 5 одинаковых;
- `R` берёт случайную (последнюю) карту вместо нужной;
- `S` бьёт по последней карте, а не по той, что ближе всего к победе игрока;
- `F` не учитывает, чего игроку не хватает до победы.

**Предложение:** реализовать ИИ как оценочную функцию с тремя уровнями сложности (Лёгкий = текущая эвристика, Обычный = эвристика + защита от победы игрока в 1 ход, Сложный = 1-плай перебор с оценкой позиции). Это ~0.5 дня сверх переноса. **Требует подтверждения (см. §9, D-6).**

## 8. Расхождения кода и внутриигрового текста правил

| # | Текст в игре | Фактическое поведение | Что делать |
|---|---|---|---|
| 8.1 | «Соберите **последовательность** F-I-R-S-T» | Порядок не проверяется, нужен просто набор из 5 разных букв | **Исправить текст**, поведение оставить (D-1) |
| 8.2 | «S — переместите карту из SPACE противника в его DISCARD» | Верно, но название «STEAL/Кража» вводит в заблуждение | Оставить механику, уточнить описание |
| 8.3 | «Максимум 7 карт, лишние автоматически сбрасываются» | Сбрасывается именно последняя добранная, без выбора | Оставить, но написать явно (D-2) |
| 8.4 | «T — в следующий ход противник сбросит 1 карту» | Несколько T подряд дают только 1 сброс: счётчик обнуляется, а не уменьшается | Требует решения (D-3) |

## 9. Открытые решения (нужно подтвердить до M2)

| ID | Вопрос | Рекомендация |
|---|---|---|
| **D-1** | `FIRST` — набор или последовательность? | **Набор** (как в коде). Требование порядка сделает партии заметно длиннее и запутает игрока |
| **D-2** | Кто выбирает карту при переполнении руки? | **Оставить авто-сброс последней добранной.** Модалка на каждый лишний добор раздражает |
| **D-3** | Стакаются ли ловушки T? | **Сделать декремент вместо обнуления** — 2×T заставят сбросить по карте в двух следующих ходах. Это чинит явный баг и делает T осмысленной |
| **D-4** | Срабатывание запрета съедает карту и ход целиком | **Оставить как есть** — это цена риска, механика работает |
| **D-5** | Что видит игрок про наложенный на него запрет? | **Оставить скрытым** (только факт запрета), это ядро блефа в игре |
| **D-6** | Уровни сложности ИИ | **Сделать 3 уровня**, по умолчанию «Обычный». Текущий ИИ слишком пассивен для красивой игры |
| **D-7** | Ускорение/пропуск анимаций | **Добавить** переключатель «быстрые анимации» в настройки |
| **D-8** | Сохранение партии между запусками | **Не делать** в v2.0. Партия короткая, оправдания нет |
| **D-9** | Формат карты: сейчас альбомный (~1:0.72), в руке квадратный | **Перейти на портретный 2:3.** Без этого HS-подача и композиция «буква + иллюстрация» невозможны. Раскладка стола перестраивается под это (см. [03-art-style-bible.md](03-art-style-bible.md) §6) |

Формат: **MP3, 44.1 кГц, стерео, 128 кбит/с**, зацикленная, ≤ 2.5 МБ на трек.

## 4. Обработка перед вставкой

Для каждого файла (Audacity или `ffmpeg`):
1. Обрезать тишину в начале и конце (порог −45 дБ), оставить 10 мс запаса.
2. Нормализовать пик до **−1 дБ**, привести громкость к **−16 LUFS** для SFX и **−20 LUFS** для музыки (музыка должна быть заметно тише).
3. Убрать субнизы фильтром HPF 60 Гц у SFX — на телефонных динамиках они только «бубнят».
4. Для музыки — выставить точки бесшовной петли, проверить на слух 3 круга подряд.
5. Экспорт в MP3 по параметрам выше.

```bash
# нормализация громкости и конвертация
ffmpeg -i raw.wav -af "highpass=f=60,loudnorm=I=-16:TP=-1:LRA=11" -ac 1 -b:a 128k sfx_card_place.mp3
```

## 5. Реализация

```
audio/
├── SoundManager.kt   # Map<SfxId, Sound>, play(id, volume, pitch)
└── MusicManager.kt   # play(track, fadeIn), crossfadeTo(track)
```

- Все `Sound` загружаются через `AssetManager` в основном наборе.
- **Вариативность:** для часто повторяющихся звуков (`sfx_card_place`, `sfx_card_draw`, `sfx_ui_click`) при каждом проигрывании выставляем случайный `pitch` в диапазоне **0.94–1.06**. Это дёшево и убирает эффект «пулемёта из одного сэмпла».
- Ограничение: не более 6 одновременных `Sound` — иначе на слабых Android каша.
- Громкости SFX и музыки — раздельные слайдеры в настройках, хранятся в `Preferences`.

## 6. Платформенные особенности

| Платформа | Что учесть |
|---|---|
| **Web (TeaVM)** | Браузер не даёт стартовать аудио до первого пользовательского жеста. Решение: `MusicManager` стартует не на загрузке, а по первому тапу/клику. Пока звука нет — не показывать иконку «звук включён» как активную |
| **Android** | Обязательно `pause()`/`resume()` музыки в жизненном цикле, иначе играет в фоне. Реакция на аппаратные кнопки громкости — системная, ничего не делаем |
| **iOS** | Уважать «беззвучный режим» устройства (по умолчанию RoboVM использует `AVAudioSessionCategoryAmbient` — это правильное поведение для игры) |
| **Desktop** | Ничего особенного |

# 06 — Спецификация анимаций и VFX, v2 («Стол гика», принята 19.08.2026)

Каталог сохраняет ID v1 (A-01…A-38), описания и числа заменены на принятые в арт-лаборатории (прототипы `docs/gdx/12-art-direction-lab/e*/lab.html`, числа — [e7-integration/SPEC.md](12-art-direction-lab/e7-integration/SPEC.md) §4). Предыдущая версия — `06-animation-spec-v1.md`.

Принципы те же: анимация объясняет правило; `AnimationDirector` проигрывает события последовательно; скорости `Normal ×1 / Fast ×0.6 / Instant ×0`; тап — пропуск; полный ход ИИ ≤ 2.5 с при Normal. Новое: **idle существует всегда** (карты, лампа, пыль) и не блокирует ввод; эффекты — **жетоны**, не свечение; ничто не накладывается на карты.

## 1. Кривые

`swingOut` (scale 2) — полёты и ховер · `pow2In` — уход в лоток, падение жетона · `pow3Out` — качение кубика · `sineOut` — маркер хода, перелёты UI · `bounceOut` — не используется (кубики — `pow3Out` с синусоидальными подскоками) · `elasticOut` — нет.

## 5. Что осознанно не анимируем

Счётчики на фишках — просто меняем число. Лог — мгновенно. Фон — статичен, кроме лампы и пыли. Параллакса нет. Покачивания фигурок нет.

## 6. Реализация

- `AnimationDirector` как сейчас (очередь колбэков) + отдельный idle-контур (лампа, пыль, дыхание руки), который не блокирует ввод.
- 3D-наклон карты: матрица `SpriteBatch.setTransformMatrix` / вершинный шейдер.
- Тряска: смещение камеры с затуханием ×0.86/кадр.
- Частицы: `ParticleEffect` или простой эмиттер (пыль, иней, конфетти).
- Кубик: меш-куб с 6 текстурами (или спрайт-лист 24 кадра).
- Бюджет: ход ИИ с эффектом ≤ 2.5 с при Normal (розыгрыш 0.5 + жетон 0.56 + действие 0.45 + снятие 0.3 + паузы).

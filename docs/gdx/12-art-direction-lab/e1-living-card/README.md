# E1 — Живая карта

**Гипотеза.** 70 % ощущения «мёртвости» — это карта, которая не дышит и не отвечает. Если одна карта во всех состояниях (idle, ховер, розыгрыш с ударом, добор, запрет, сброс) станет живой, стол оживёт наполовину ещё до фона и эффектов.

**Что это.** Движущийся HTML-прототип на реальных PNG в стиле якоря A1: коврик, две карты-литеры (F, S), рубашка. Три **характера движения** — переключаются на панели, каждый описан числами (длительность, кривая, амплитуда), которые уезжают в `06-animation-spec.md` и в Scene2D без пересчёта: имена кривых совпадают с `Interpolation` libGDX (`sineOut`, `pow3Out`, `swingOut`, `pow4In`…).

| Характер | Идея | Риск |
|---|---|---|
| **Мягкий** | спокойный «дорогой» стол: длинные плавные дуги, минимум тряски | вялость |
| **Упругий** | Balatro-настроение: перелёт-возврат, сквош на ударе, живая рука | суета |
| **Тяжёлый** | карта — вещь с весом: короткий замах, быстрое падение, сильный удар, стол вздрагивает | медленно на сотой партии |

**Как смотреть** — [lab.html](lab.html) (локально: `python3 -m http.server` в `docs/gdx/12-art-direction-lab/`, открыть `e1-living-card/lab.html`) или опубликованный артефакт. Лучше на десктопе с мышью (ховер и наклон к курсору), потом на телефоне.

1. Ничего не трогать 10 секунд — карты в руке дышат (П2). Не должно выглядеть скриншотом и не должно раздражать.
2. Водить мышью над картой в руке — подъём, наклон к курсору, тень.
3. Клик по карте — розыгрыш: полёт по дуге, приземление, вспышка света на коврике, пыль, тряска стола, рука смыкается.
4. «Ход ИИ» — карта прилетает сверху рубашкой и переворачивается в полёте.
5. «Добор» — карта из колоды в руку с переворотом; стопка вздрагивает.
6. Клик по карте на столе (или «Запрет F») — короткая тряска «защёлкивания», иней, затем карта уезжает в лоток сброса.
7. Галочка «замедление ×3» — разглядеть кривые.

**Что решает судья**

| Вопрос | Варианты |
|---|---|
| Характер движения | мягкий / упругий / тяжёлый / гибрид («ховер как упругий, удар как тяжёлый») |
| Idle-дыхание | амплитуда ок / меньше / больше / убрать |
| Тряска стола на ударе | ок / меньше / убрать |
| Наклон к курсору | ок / меньше / убрать |
| Чего не хватает | свободный текст |

Оценка по П2 (живёт, не мешает) и П3 (понятно, что произошло: розыгрыш, добор, запрет, сброс) — 0–2.

**Что здесь намеренно не сделано** (это другие эксперименты): буква и компоновка карты (E2), миниатюры игроков и живой фон (E3), остальные эффекты I/R/S/T (E4), кубики/победа (E5), кнопки/модалки (E6).

## Вердикт судьи (18.08.2026)

Характер — **упругий**; idle — ок; тряска — ок; наклон — больше («эффект реального стола, а не перпендикулярно взгляду»). «Всё нравится, продолжай». Внесено: tilt 20°, rest −8°. Итоговые числа — [RESULT.md](RESULT.md).

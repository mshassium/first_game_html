# E6 — UI отвечает

**Гипотеза.** Интерфейс в мире «стола гика» — тоже предметы на столе: меню, счётчики, кнопки и окна выбора сделаны из тех же материалов, что и всё остальное, и реагируют как вещи (приподнимаются, вдавливаются, пылят).

**Два направления** (переключаются в прототипе [lab.html](lab.html), заготовки в `props/` по [PROMPTS.md](PROMPTS.md)):

| | U1 «карандаш и бумага» | U2 «дерево и латунь» |
|---|---|---|
| Откуда растёт | блокнот из E5 (результат партии) | жетоны из E4 (эффекты) |
| Меню | блокнот; пункты — слова, обведённые карандашом | деревянная дощечка; пункты — планки с латунными табличками |
| HUD (рука 5/7, колода, сброс, таймер) | отрывной блокнотик с карандашными цифрами | латунная табличка с выгравированными цифрами |
| Кнопки | бумажные бирки с люверсом | планки с латунной табличкой |
| Окна выбора (буква запрета, карта для сброса) | стикер на коврике, буквы на бирках | дощечка, буквы на латунных табличках |
| Пауза | стикер с тремя пунктами | дощечка с тремя планками |
| Недоступная кнопка | зачёркнуто карандашом, бледно | табличка потускнела |
| Характер | домашний, самодельный, лёгкий | основательный, «как жетоны», дороже |

**Отклик** (общий для обоих): ховер — приподнять на 3 px и усилить тень (0.13 с, `swingOut`); нажатие — вдавить (scale 0.97, 1 px вниз) + пыль; карты в окне выбора поднимаются при наведении на 22 px.

**Что решает судья.** U1 / U2 / гибрид (например, «меню и результат — блокнот, HUD и кнопки — латунь»); что не так в отклике; П5 (один мир) и П2.

## Вердикт судьи, раунд 1 (19.08.2026)

Ни U1, ни U2. Контекст: партия F!RST — перерыв между долгими играми, значит интерфейс должен быть собран из **их** элементов, фигурок, обозначений и атрибутики, в идеале комбинируя: блокнот заметок из MTG (с более стилизованным шрифтом), уникальные атрибуты Hearthstone, Balatro и т. д.

## Раунд 2 — U3 «Снаряжение гика»

Интерфейс собран из вещей долгих игр (в духе, без логотипов и копий), `props/G_*`:

| Элемент UI | Предмет | Откуда дух |
|---|---|---|
| Меню, окна выбора, пауза, результат | блокнот счёта жизней, рукописный почерк (Noteworthy/Bradley Hand; в игре — рукописный шрифт) | MTG |
| «Играть» в меню | коробка колоды (взять колоду = играть), рядом спин-даун d20 | MTG |
| HUD: рука 5/7, колода, сброс | фишки со значениями | Balatro / покер |
| Таймер хода | ~~горящий фитиль~~ → **свеча в латунном подсвечнике**, сгорает за ход (высота тела уменьшается, пламя опускается, ореол) | стол-берлога ночью |
| Подтверждение / конец хода | большая латунная кнопка на деревянной шайбе | Hearthstone |
| Выбор буквы запрета | картонные жетоны-выбивки с буквами | настольные жетоны |
| Кнопки «правила / меню» | меловые обводки на коврике | — |

U1 и U2 оставлены в переключателе для сравнения.

## Вердикт судьи, раунд 2 (19.08.2026)

U3 нравится. Убрать фитиль — точная копия Hearthstone; для отсчёта времени — многогранный кубик из MTG или свеча, которая медленно сгорает.

## Раунд 3

Таймер хода — **свеча** (`props/G_CANDLE.png`, камера как у фигурок): за ход тело свечи укорачивается, пламя опускается, ореол света на коврике. Альтернатива на будущее — спин-даун d20 как счётчик ходов (уже лежит в меню).

## 2. Карта

- Портрет 2:3. Кремовый картон, тонкий кант цвета школы, **одна гигантская гуашевая буква ~65 % высоты**, дудл-эмблема внизу. Два скина: C1 (кремовый) и C3 (цветное лицо, кремовая буква) — переключение в настройках.
- **Буквы запекаются в арт** (5 карт × 2 скина), исключение из правила «текст шрифтом» в `02-architecture.md`. `×N` стопки, счётчики, подписи — по-прежнему шрифтом.
- В руке карты лежат с постоянным наклоном `rotateX −8°` (матрица/шейдер), ховер — наклон к курсору до 20° по обеим осям.

## 3. Раскладка экрана боя (принцип P2: мало предметов, у каждого своё место, воздух)

Относительно W×H; карта CW = min(0.15H, 0.068W), CHh = 1.5CW. Раунд 1 E7 был отвергнут как «мусор повсюду» — правая колонка громоздилась, HUD наезжал на руку противника. Принято:

| Элемент | Позиция |
|---|---|
| Фигурка противника / игрока | x = 0.145W, y = 0.10H / 0.52H, ширина 1.4CW; контактная тень под базой |
| Гнёзда жетонов | колонка правее фигурки, 2 тонких круга Ø0.9CW, α 0.16 |
| Песочные часы (ход) | **под базой** активной фигурки (x = mini.x + 0.32w, y = mini.y + 0.95h) |
| Ряды SPACE | центр cx = 0.555W; 5 слотов по CW с шагом 1.22CW; y = 0.31H и 0.60H |
| Колоды | одна колонка справа от рядов (x = x0 + rowW + 0.7CW), по одной на сторону, на высоте своего ряда |
| Лотки сброса | **над** колодой противника и **под** колодой игрока (1.16CW × 0.62CHh) — не между рядами |
| Счётчик колоды | одна маленькая фишка Ø0.55CW правее колоды игрока; отдельного HUD нет (рука и сброс видны сами) |
| Свеча-таймер | правее колоды противника, на дереве (0.7CW × 1.54CW) |
| Кнопка «конец хода» | правый нижний угол стола на дереве (Ø1.15CW, x = W − 1.5CW, y = 0.72H) |
| Рука игрока | снизу по центру cx, веер; рука противника — сверху, масштаб 0.62, рубашкой |
| Служебные «правила / меню» | в партии — по кнопке паузы/блокноту, на коврик не выносим |

Камера — строго сверху; карты противника лежат лицом к игроку.

## 4. Движение (принятый характер «упругий», E1) — см. [e1-living-card/RESULT.md](../e1-living-card/RESULT.md)

Кривые — `Interpolation` libGDX. Глобальный множитель скорости — как сейчас в `AnimationDirector`; «замедление ×3» — отладочный режим.

| Движение | Числа |
|---|---|
| Idle руки | ±3 px, период 2.4 с, ±1.2°, случайная фаза |
| Ховер | подъём 26 px, ×1.10, наклон к курсору ≤20°, покой −8°, 0.14 с `swingOut` |
| Розыгрыш | 0.42 с `swingOut`, дуга 90 px, ±6°; ИИ ×1.2 с flip в середине |
| Импакт | сквош 0.12, тряска стола 4 px затухающая, 12 пылинок, лампа +0.05 |
| Смыкание руки | 0.22 с `swingOut` |
| Добор | 0.36 с `swingOut`, дуга 60, flip, колода ×0.96 за 0.18 с |
| Сброс | 0.34–0.40 с `pow2In`, наклон ±20°, конечный ×0.7, поворот ±12° в лотке, 5 пылинок |
| Жетон | падение 0.38 с `pow2In` с высоты 140 px, ×1.25→1, удар: тряска 5, 10 пылинок, отскок ×1.08 за 0.18 с; снятие 0.3 с вверх с поворотом 15° и растворением |
| Запрет сработал | карта летит к слоту запрета (0.45 с), дрожь 5°×10 за 0.3 с, замок ×1.15, иней 0.4 с, пауза 0.3, в лоток; вымпел и замок снимаются |
| Капкан сработал | захлопывание ×1.2 за 0.3 с + тряска 6, карта руки подскок 26 px, в лоток |
| Маркер хода | перелёт 0.5 с `sineOut`, дуга 50 px, без поворота |
| Фигурка | статична; прыжок по клику / на победу 40 px за 0.5 с `sineOut`, **без вращения**; на удар — подскок 4 px |
| Лампа | α 0.50 ± 0.06 (период ~9 с) ± шум ×0.8; виньетка по краям 0.20; удар +0.05…0.16; поражение ×0.65 |
| Пыль в луче | 120 пылинок r 1–3.4 px, видны только в конусе лампы; пар от кружки — мягкие круги α 0.10, поднимаются 1.6–2.4 с |
| Кубик | влетает со своей стороны, путь к точке 1.4 с `pow3Out`, кувырок: rotateX −(3–4)·360 + rotateY ±(1–2)·360, доворот до грани; 3 подскока амплитудой 1.6w·(1−t)²; победивший подпрыгивает 0.7w; убираются за 0.45 с |
| Раздача | по карте поочерёдно, интервал 0.14 с |
| Победа | волна по ряду (подъём 28 px, stagger 0.12), тряска 6, лампа +0.16, конфетти 90 бумажек, фигурка прыгает; блокнот выезжает 0.55 с `swingOut` |
| Поражение | волна по ряду противника, лампа ×0.65 за 0.8 с, мои карты `brightness .6 saturate .7` |
| Смена экрана | лампа выкл 0.4 с → в темноте перестроить стол → вкл 0.6 с + вспышка 0.14 |
| UI-кнопка | ховер −3 px за 0.13 с, нажатие ×0.97 + пыль |
| Свеча-таймер | `--burn` 0→100 % за длительность хода: тело `clip` сверху, пламя опускается |

## 5. Что нужно в движке (чего сейчас нет)

1. **3D-наклон карты** (ховер, покой −8°): матрица трансформации в `SpriteBatch` или вершинный шейдер.
2. **Партиклы**: пыль, иней, конфетти — `ParticleEffect` или свой простой эмиттер (в прототипах — 3 вида частиц).
3. **Тряска камеры** с затуханием ×0.86/кадр.
4. **Объёмный кубик**: меш-куб с 6 текстурами (или предрендеренный спрайт-лист кувырка 24 кадра).
5. **Лампа**: аддитивный спрайт-градиент с анимированной α + виньетка; «ночь» — чёрный оверлей с точкой лампы.
6. **Шрифт рукописный** для блокнота/меню (подобрать с кириллицей; в прототипе системный).
7. **Хромакей/альфа** — финальные предметы генерируются с альфой (artgen: чистый фон → вырезка).

## 6. Порядок работ (предложение)

1. Ассеты: финальная генерация BG (+портрет), 10 карт + рубашка, 2 фигурки, маркер, 7 жетонов, 12 граней кубиков, блокнот, 6 UI-предметов — через artgen по промптам лаборатории. Атласы.
2. Экран боя: раскладка §3 на новом фоне, фигурки, гнёзда, HUD-фишки, свеча, кнопка.
3. Карты: скины C1/C3, наклон, ховер, idle.
4. AnimationDirector: числа §4 (розыгрыш, импакт, добор, сброс, рука).
5. Эффекты-жетоны F/I/R/S/T + запрет/капкан.
6. Ритуалы: кубики, раздача, победа/поражение, блокнот, смена экрана лампой.
7. Меню и окна на блокноте, пауза, настройки (скин карт).
8. Звук (07) — отдельно.

Стоимость лаборатории: 86 генераций, ≈ $1.93.

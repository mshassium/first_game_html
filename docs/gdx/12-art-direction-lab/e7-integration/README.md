# E7 — Целостность: сцена партии и спецификация

**Что это.** Всё принятое в E0–E6 в одной автоматической сцене ([lab.html](lab.html), кнопка «Сыграть сцену», ~45 с): лампа включается → меню-блокнот → коробка колоды → кубики решают ход → раздача → ходы с жетонами (капкан, замок с вымпелом, запрет сработал, росток на колоду) → набор F·I·R·S·T → победа с блокнотом → лампу выключили → меню. Шаги можно запускать по отдельности.

**Спецификация для переноса в libGDX** — [SPEC.md](SPEC.md): инвентарь ассетов, карта, раскладка, все числа движения, что нужно в движке, порядок работ. Обновлены базовые документы проекта: `03-art-style-bible.md` (v2 «Стол гика»), `06-animation-spec.md` (v2), `05-prompt-book-v3-geek-table.md`.

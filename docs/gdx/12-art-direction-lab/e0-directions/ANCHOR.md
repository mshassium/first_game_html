# Якорь стиля F!RST — «Стол гика» (итог E0, 18.08.2026)

Принят судьёй по рендеру **A1** (`out/A1_gpt-5.4-image-2_1.png`, `_2.png`). Это единственный источник истины по визуалу до конца лаборатории; при переносе в игру обновляет `03-art-style-bible.md`.

## Мир и история

F!RST — быстрая игра «между делом», в которую гики играют между партиями в большие ККИ. Экран игры — **их стол**: домашняя игровая комната ночью, тёплая лампа, полки с коробками настолок и расписанными миниатюрами за спиной, кубики, коробки колод, протекторы, чипсы, кружка. История рассказывается предметами, без текста и без выдуманного лора. Атрибутика узнаваема *по духу*, но без логотипов и копий чужих персонажей (герои — архетипы: космический рыцарь, орк-вождь, эльфийка-лучница, гном с молотом).

Отвергнуто и почему: таверна (D1/D5c) — это уже Hearthstone; кабинет типографа (D2) — слишком реалистично; мультяшный (D3) — дёшево; таро (D4) — темно и не читается; портреты-иконки — инородны.

## Подача

- **Живопись**, видимый мазок, тёплые толстые дружелюбные формы. Не фотореализм, не 3D, не флэт, не контурный мультфильм.
- **Свет** — одна тёплая лампа сверху-справа, золотое пятно на коврике с мягким спадом; уют = свет, а не количество предметов.
- **Камера** — почти строго сверху, без перспективного сжатия дальнего ряда. Карты противника лежат «лицом к игроку».

## Стол (раскладка экрана боя)

| Зона | Что это физически |
|---|---|
| Поле | тёмный спокойный неопреновый коврик, рунный узор только по канту; центр пустой, чтобы карты «выстреливали» |
| SPACE ×2 | два ряда по 5 напечатанных на коврике зон, ряды одинакового размера |
| Рука | 5–7 карт веером у нижней кромки, чуть крупнее |
| Игроки | две крупные (~1.3 высоты карты) расписные **миниатюры на толстых жетонах-подставках** с цветным ободком (противник сверху, игрок снизу, слева) |
| Колода | стопка рубашкой вверх справа |
| Сброс | деревянный **лоток** (dice tray) справа, карты в нём видны |
| Окружение | край стола, лампа, кружка, чипсы, d20/d6, коробки колод, полки — по краям, не в зоне игры |

## Карта

Портрет 2:3. **Кремовый плотный картон в прозрачном протекторе**, тонкая линия-кант цвета школы, лёгкие потёртости. **Одна гигантская рукописная буква** (гуашь, мазок) цвета школы занимает ~65 % высоты; маленькая дудл-эмблема внизу по центру. Никакого арта-иллюстрации, никакой рамки-багета. Цвета школ сохранены: F лазурь `#9CC8FF`, I нефрит `#A9FFCF`, R янтарь `#FFD195`, S багрянец `#FF9AA4`, T аметист `#C6B3FF` (в живописи — насыщеннее, гуашью). Рубашка — индиго с кремовым рунным кантом.

Точную компоновку буквы (размер, положение, эмблема, поведение в стопке ×N, читаемость на 960×540) уточняет **E2**.

## Эффекты — жетоны (принято в E4, 19.08.2026)

**Грамматика, единая для всех пяти эффектов:** жетон падает сверху на *место* (не на карту) — слот, колоду, лоток, коврик у карты, у руки — с глухим ударом и пылью; затронутая карта едет по простой прямой; жетон поднимается. Карты сами никуда не «бегают», ассеты не накладываются друг на друга, свечения нет — только удар, пыль и след (иней).

**Жетоны** — один стиль, эталон капкан T: толстая деревянная шайба с натуральной древесиной в центре, крашеный ободок цвета школы, расписной/металлический предмет лежит на дереве (`e4-effects/props/`).

| Эффект | Жетон | Место | Что едет |
|---|---|---|---|
| F запрет | замок + вымпел с буквой | слот запрета слева от ряда противника | — (висит); при срабатывании карта противника останавливается *рядом* с замком, дрожит, покрывается инеем и едет в его лоток; замок и вымпел снимаются |
| I прирост | росток | на твою колоду | верхняя карта колоды → в руку |
| R возврат | перо | в твой лоток сброса | карта из лотка → в руку |
| S кража | рука-латница | на коврик под картой противника | карта противника темнеет → в его лоток |
| T ловушка | капкан (открыт → захлопнут) | у руки противника | висит; на его ходу захлопывается на месте, карта его руки вздрагивает → в его лоток |
| Победа / поражение | E5 — см. «Ритуалы» | | |

Отвергнуто: свечение как носитель смысла (не наглядно), «рука тени» и любые эффекты-наложения (не в стиле), карты, которые сами прыгают и что-то делают (неестественно).

## Игроки и живой стол (принято в E3, 19.08.2026)

- **Игроки — расписные миниатюры-архетипы на деревянных шайбах** (`e3-living-table/props/TOP_OPP.png` — маг-менталист в синем капюшоне, дух MTG; `TOP_ME.png` — трактирщик-дварф с кружкой, дух Hearthstone; не копии конкретных персонажей). Стоят на коврике слева, ~1.3 высоты карты; **статичны**, клик — прыжок с оборотом; вздрагивают от удара по столу; никаких покачиваний и увеличений.
- **Ракурс любого предмета = ракурс стола: строго сверху (~70–75°)**, база — широкий эллипс. Свет и тень **запекаются при генерации** (референс — стол/референс судьи), поверх ничего не рисуется; под базой — контактная тень. Свет предметов — «как есть» (без тонировки).
- **Ход показывает предмет — песочные часы** на золотой шайбе (`TOP_TURN.png`), перелетают к активной миниатюре по мягкой дуге без поворотов. Никакого свечения хода.
- **Гнёзда для жетонов** напечатаны на коврике колонкой у каждой миниатюры (запрет · ловушка), тонкий орнамент внутри.
- **Лампа дышит** (медленное мерцание) и **вздрагивает от удара**; **пыль** в луче лампы; **стол вздрагивает** на удар и на события. Параллакса нет.
- Фон экрана боя — `e3-living-table/out/BG_*.png` (берлога без карт).

## Ритуалы (принято в E5, 19.08.2026)

- **Начало партии:** два объёмных d6 (реальный масштаб — ~⅓ ширины карты; кубик противника **синий** и влетает **с его стороны**, мой **зелёный** — с моей) катятся по коврику кувырками, подскакивают, тормозят; победивший подпрыгивает; **песочные часы летят к первому игроку**; кубики убирают со стола; раздача по 5 карт поочерёдно, карты игрока переворачиваются в полёте.
- **Победа:** волна по ряду (карты подпрыгивают по очереди), стол вздрагивает, лампа вспыхивает, фигурка подпрыгивает (без вращения), бумажное конфетти; **экран результата — блокнот** с того же стола, надпись движком, кнопки — обведённые карандашом слова.
- **Поражение:** волна по ряду противника, его фигурка подпрыгивает, **лампа приглушается на треть**, мои карты тускнеют; блокнот «Поражение».
- **Смена экрана:** «лампу выключили → в темноте стол убрали → включили», вместо кроссфейда.
- **Масштаб предметов на столе — реальный относительно карты** (жетон ≈ 0.6–0.9, кубик ≈ 0.34, фигурка ≈ 1.3 высоты карты). Фигурки **никогда не вращаются**.

## Интерфейс — «снаряжение гика» (принято в E6, 19.08.2026)

Интерфейс собран из атрибутики долгих игр, в которые играют за этим столом, — **в духе, без логотипов и буквальных копий узнаваемых механик-визуалов** (фитиль-таймер отвергнут как копия Hearthstone). Ассеты — `e6-ui/props/G_*.png`.

| Элемент | Предмет |
|---|---|
| Меню, окна выбора, пауза, результат | **блокнот счёта** (дух MTG) с рукописным почерком; пункты — слова, обведённые карандашом |
| «Играть» | **коробка колоды** на столе (взять колоду = играть); рядом спин-даун d20 (резерв — счётчик ходов) |
| HUD: рука / колода / сброс | **фишки** со значениями (дух Balatro/покера) у верхнего края коврика |
| Таймер хода | **свеча в подсвечнике** — сгорает за ход (тело укорачивается, пламя опускается, ореол на коврике) |
| Подтверждение / конец хода | **большая латунная кнопка** на деревянной шайбе справа от рядов |
| Выбор буквы запрета | **картонные жетоны-выбивки** с буквами на блокноте |
| Выбор карты для сброса | запись в блокноте, карты руки поднимаются при наведении |
| Служебные кнопки в партии | меловые обводки на коврике |
| Отклик | ховер — приподнять на 3 px + тень (0.13 с); нажатие — вдавить (scale 0.97) + пыль; недоступно — бледно/зачёркнуто |
